# 就活トラッカー 使用ガイド

企業情報、選考状況、面接記録、予定、待遇をまとめて管理するアプリです。登録したデータはパソコン内に保存されます。企業情報や予定の管理はオフラインで使えます。AIによる生成や更新確認にはネットワーク接続が必要です。

## 利用できる環境

現在は開発版で、ビルド済みの安定版アプリは配布していません。ソースからの準備が必要です。

| 環境 | 確認状況 |
| --- | --- |
| macOS・Apple Silicon | ビルド・画面表示・基本操作を確認済み |
| Windows x64 | ビルド・起動を確認済み |
| Windows ARM64・Linux | 実機での起動は未確認 |

Node.js **24.22.1以降の24系、または26.12.1以降の26系**を別途インストールしてください。対応していない版では起動を停止します。アプリの更新だけではNode.jsは更新されません。

## 準備と起動

最初に、リポジトリをダウンロードまたはcloneして、そのフォルダーをターミナルで開きます。

### macOS・Apple Silicon

Node.jsとXcode Command Line Toolsが必要です。

```sh
npm ci --ignore-scripts
npm run build
npm start
```

ビルド後は`dist/mac-arm64/就活トラッカー.app`を開いて起動できます。現在のビルドはローカル実行用で、Developer ID署名・公証は行っていません。

別のNode.jsを指定して起動する場合は、実行ファイルの絶対パスを指定します。

```sh
JOB_TRACKER_NODE_PATH="/absolute/path/to/node" "/absolute/path/to/node" scripts/start.cjs
```

ソースを変更・更新した場合は、`npm ci --ignore-scripts`と`npm run build`を再実行してください。

### Windows x64

対応するNode.js、.NET 10 SDK、.NET 10 Desktop Runtime、Microsoft Edge WebView2 Runtimeが必要です。PowerShellで次を実行します。

```powershell
npm ci --ignore-scripts
.\platforms\windows\build.ps1 -Runtime win-x64
& ".\dist\win-x64\JobTrackerHost.exe"
```

ARM64版やLinux版を利用する場合は、実機での動作が未確認であることに注意してください。

## 企業を登録する

企業情報を自分で入力する方法と、「AI / プロンプトで追加」から取り込む方法があります。

AIを使う場合も、接続設定を作らずにプロンプトをコピーし、普段使っているAIへ貼り付けられます。回答のJSONをアプリへ戻してプレビューを確認し、登録してください。AIが生成した内容や出典は、保存する前に確認してください。

## カンバンで選考を管理する

ホーム画面には8つの状態が並びます。通常の幅では4列×2行、狭いウィンドウでは2列または1列で表示します。各状態の企業は、列の中で上下にスクロールできます。

- **企業カードを選ぶ**：企業の詳細を開きます。企業名にTabキーで移動して、Enter／Spaceでも開けます。
- **「前へ」「次へ」を選ぶ**：企業の選考状況を変更します。
- **状態の見出しや余白を選ぶ**：その状態の企業一覧を拡大します。
- **「戻る」またはEscape**：拡大表示を閉じ、元の列とスクロール位置に戻ります。

企業一覧ページへの切り替え、日程・締切の確認、待遇の比較も画面上部から行えます。OSで動きを減らす設定を有効にしている場合は、拡大・縮小のアニメーションを省略します。

## AIへの接続を設定する

「AI / プロンプトで追加」→「各種エージェントを登録する」から設定します。実アカウントでの接続・課金・全モデルの動作は未検証です。接続設定の登録だけでは、企業調査の通信や生成は行いません。

### APIキーを使う

提供元、表示名、モデルID、APIキーを入力して登録します。モデルIDは提供元の管理画面で確認してください。

対象はOpenAI、OpenRouter、Claude、Gemini、Grok、Perplexity、DeepSeek、Mistral、Z.AI、Kimi、MiniMaxです。通常のAPI利用は、チャットサービスの月額契約とは別に料金が発生する場合があります。MiniMaxは通常APIとM Planに対応します。

登録後に企業追加画面へ戻り、接続先を選んで生成します。**表示されたプロンプトには就活プロフィールが含まれ、選んだ提供元へ送信されます。** 本文を確認してから実行してください。生成結果はプレビューを確認するまで企業DBへ保存されません。

接続設定を削除しても、提供元のAPIキーは失効しません。不要になったキーは、提供元の管理画面でも削除してください。

### GitHub Copilotを使う

Copilotの利用契約と、このアプリ専用のGitHub OAuth AppのClient IDが必要です。

1. GitHubのSettings → Developer settings → OAuth AppsでOAuth Appを作成し、**Enable Device Flow**を有効にします。
2. 「各種エージェントを登録する」のCopilot連携欄へClient IDを入力して保存します。Client Secretは入力しません。
3. 「GitHubでCopilotにログイン」を選び、表示されたコードをGitHub上で入力して承認します。アプリ名と要求権限を確認してください。
4. 「モデル・利用枠を確認」で接続状態を確認します。
5. 企業追加画面へ戻り、Copilotを選んで生成します。

利用枠・追加料金・利用可能なモデルは契約や組織の設定に依存します。連携解除はアプリ内の設定に加え、必要に応じてGitHub側のOAuth Appの認可も取り消してください。

ChatGPT連携も登録画面にありますが、実アカウントでの利用資格や動作は未検証です。接続できない場合は、プロンプトのコピーと回答の貼り付けを利用できます。

## データの保存・バックアップ・旧版からの移行

データ管理画面で、JSONバックアップの作成、取り込み前のプレビュー、取り込み、直前の取り込みの巻き戻しができます。

旧版のSQLiteデータは、データ管理画面で旧DBファイルを選択して取り込みます。内容をプレビューで確認してから実行してください。旧版のパスワードは取り込みません。

バックアップには就活プロフィールや企業メモなどの個人情報が含まれます。認証トークンは含みません。共有やクラウド保存の前に内容を確認してください。企業DB・プロフィール・バックアップ自体は暗号化されていません。AIの認証情報はOSの保護機能を使って暗号化保存します。

標準の保存先は次のとおりです。

| OS | 保存先 |
| --- | --- |
| macOS | `~/Library/Application Support/jp.jobtracker.app` |
| Windows | `%APPDATA%\jp.jobtracker.app` |
| Linux | `${XDG_CONFIG_HOME:-~/.config}/jp.jobtracker.app` |

アプリを削除してもデータは残ります。完全に削除する場合は、必要なバックアップを取ってから上記の保存先を削除してください。OSに保存された認証鍵やWebViewのキャッシュは、別に残る場合があります。

## テーマと起動時ロック

ヘッダーの「設定」で、システム／ライト／ダークのテーマと4種類のアクセント色を選べます。

起動時ロックは任意で、初期状態ではオフです。macOSのTouch IDなどのOS認証、Windows Helloに対応する設定があります。実際の生体認証・PIN認証の成功は未検証なので、有効化する前にOS側で本人確認手段を設定してください。Linuxと通常のブラウザーでは有効にできません。

認証のキャンセル・失敗や、設定を読み込めない場合は起動を停止します。起動時ロックはDB全体の暗号化ではありません。パソコンのログインやディスク暗号化もあわせて管理してください。

## macOSのショートカット

| キー | 操作 |
| --- | --- |
| ⌘Q | アプリを終了 |
| ⌘W | ウィンドウを閉じる |
| ⌘M | 最小化 |
| ⌘H / ⌥⌘H | アプリを隠す / ほかのアプリを隠す |
| ⌘X / ⌘C / ⌘V / ⌘A | 切り取り / コピー / 貼り付け / 全選択 |
| ⌘Z / ⇧⌘Z | 入力の取り消し / やり直し |
| ⌃⌘F | フルスクリーンの切り替え |
| Escape | モーダルやカンバンの拡大表示を閉じる |

未保存の入力がある場合、終了やウィンドウを閉じる前に破棄確認が表示されます。取り消し／やり直しはテキスト編集用で、企業の削除や取り込みを戻す操作ではありません。

## 困ったとき

- **起動できない**：`node --version`で対応版か確認してください。macOSではターミナル起動とアプリの直接起動で、別のNode.jsが選ばれる場合があります。
- **AI接続が利用できない**：OSの認証情報保管機能、提供元の契約・モデルID・キーの状態を確認してください。手動のコピー・貼り付けでも企業を登録できます。
- **取り込みをやり直したい**：直前の取り込みなら、データ管理画面の巻き戻しを確認してください。

Google Drive同期は未対応です。アプリ内の自動更新も、配布先の設定がないため既定では無効です。更新時はバックアップを取り、利用しているソースやアプリを更新してください。
