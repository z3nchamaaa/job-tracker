# 就活トラッカー

応募先の企業情報、選考状況、面接記録、予定、待遇をパソコン内で管理するデスクトップアプリです。

**[使用ガイド：準備・起動・操作方法](docs/README.md)**

現在は開発版です。署名・公証済みの安定版アプリは配布していません。利用できる環境と未対応の機能は使用ガイドを確認してください。
